- When using [[Beyond the Veil/Veil Content/Actions/Prepared Action\|Prepared Action]] by setting a trigger, once the trigger occurs you can use a [[Beyond the Veil/Veil Glossary/Reaction\|Reaction]] to use the [[Beyond the Veil/Veil Content/Actions/Prepared Action\|Prepared Action]]. 
- You can choose not to use the [[Beyond the Veil/Veil Content/Actions/Prepared Action\|Prepared Action]] immediately as it might get triggered again within the same round.
- If the trigger doesn't happen, you simply don't use the [[Beyond the Veil/Veil Content/Actions/Prepared Action\|Prepared Action]].
- Choose a [[Beyond the Veil/Veil Glossary/Free Action\|Free Action]], single action action or single action ability.
- You cannot use [[Beyond the Veil/Veil Content/Actions/Prepared Action\|Prepared Action]] on features or abilities that already have a trigger.
- Ideally the trigger is set to be used between another's creature's actions. The [[Beyond the Veil/Veil Glossary/Director\|Director]] can decide when 'exactly' the triggers fires if there is doubt.
- The trigger must be a simple but specific conditions to be triggered. Examples:
	- Specific Ability Name to use with a clear trigger such as: 'Use [[Beyond the Veil/Veil Content/Abilities/Executioner’s Strike\|Executioner’s Strike]] when anything comes into [[Beyond the Veil/Veil Glossary/Melee\|Melee]] range.'
	- Specific Action based on another creature's action: When my ally shoots, I will use an [[Beyond the Veil/Veil Content/Actions/Interact\|Interact]] action and close the door.
