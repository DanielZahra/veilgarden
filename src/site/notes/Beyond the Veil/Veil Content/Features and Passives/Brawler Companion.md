Description:: Your [[Beyond the Veil/Veil Glossary/Companion\|Companion]] has features which resemble weapons or can use actual weapons. When choosing weapons as a function the chosen weapon is merged with the [[Beyond the Veil/Veil Glossary/Companion\|Companion]]’s [[Beyond the Veil/Veil Glossary/Natural Weapon\|Natural Weapon]], which includes all the weapon's basic traits.  If they are using features which resemble weapons, these are chosen when you create, summon or find the with through a ritual.  e.g. [[Beyond the Veil/Veil Content/Rituals/Bind Ossified Ally\|Bind Ossified Ally]] or [[Beastmaster's Bond\|Beastmaster's Bond]]. The [[Beyond the Veil/Veil Content/Features and Passives/Brawler Companion\|Brawler Companion]] allows your [[Beyond the Veil/Veil Glossary/Companion\|Companion]] to wield a [[Beyond the Veil/Veil Glossary/Two Handed\|Two Handed]] [[Beyond the Veil/Veil Glossary/Melee\|Melee]] Weapon. The companion gains the [[Beyond the Veil/Veil Content/Actions/Parry\|Parry]] action.
