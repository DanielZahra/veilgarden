- You can activate a ritual using 3 actions. [[Beyond the Veil/Veil Content/Features and Passives/Memorized Ritual\|Memorized Ritual]] can be used for rituals with 10 minutes casting time or less. If a skill check is needed, the skill check is done as part of the 3 actions.
