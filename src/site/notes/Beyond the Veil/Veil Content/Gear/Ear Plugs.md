- When you wear [[Beyond the Veil/Veil Content/Gear/Ear Plugs\|Ear Plugs]], any effect with the [[Beyond the Veil/Veil Glossary/Auditory\|Auditory]] trait has half the range when it would otherwise interact with you. 

> [!note] 🗺️
> Example: If a normal [[Beyond the Veil/Veil Glossary/Auditory\|Auditory]] effect has a range of 6, this effect has a range of 3 for you. So if you are within 6 range, you are not affected by it.
