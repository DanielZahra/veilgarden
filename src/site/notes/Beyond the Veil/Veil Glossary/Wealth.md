Wealth is a measure of value in money, loot and treasure that can be used to buy items or upgrades through [[Beyond the Veil/Veil Glossary/Campcraft\|Campcraft]]. Each [[Beyond the Veil/Veil Glossary/Wealth\|Wealth]] takes one [[Beyond the Veil/Veil Content/Gear/Backpack\|Backpack]] slot.
