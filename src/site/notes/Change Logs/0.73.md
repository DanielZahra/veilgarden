#### Inventory Management Update

- Removed [[Beyond the Veil/Veil Glossary/Wealth\|Wealth]] Storage and Cargo Storage
- Everything is now in the [[Beyond the Veil/Veil Content/Gear/Backpack\|Backpack]] system.
- When resting (you do create all campcraft unlocks) but any item that is not placed in the [[Beyond the Veil/Veil Content/Gear/Backpack\|Backpack]] is discarded. What this means is that you rest (restock everything) but stuff that isn't in your backpack doesn't make it with you.
